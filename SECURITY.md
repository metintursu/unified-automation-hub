# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private reporting instead:
**Security tab > Report a vulnerability** on this repository.

Include steps to reproduce and the affected service. I will reply as soon as I can.

## Supported versions

This project is an early release. Only the latest commit on `main` is supported.

## Notes for users

- Never commit your `.env` file.
- Change every default credential before exposing any service to a network.
- Do not expose this stack directly to the internet without hardening it first.
